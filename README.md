# Sistema de Desconto Progressivo

Programa desenvolvido em Python para calcular o desconto aplicado a uma compra e o valor final que deverá ser pago pelo cliente.

## Regras de desconto

- Compras menores que R$ 200,00: desconto de 5%;
- Compras entre R$ 200,00 e R$ 299,99: desconto de 10%;
- Compras iguais ou superiores a R$ 300,00: desconto de 15%.

## Como executar

1. Abra o arquivo `sistema_desconto.py`;
2. Execute o programa;
3. Digite o valor total da compra;
4. Confira o desconto aplicado e o total a pagar.
